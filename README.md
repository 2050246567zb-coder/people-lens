# 人物速览 · 小红书回复助手

在小红书网页端回复别人时，在输入框上方展示口语化的人物介绍，帮助你了解对方公开分享的背景、兴趣、做过的事和表达习惯。支持小众词解释和结合当前对话的回复建议。

当前版本 **0.1.8**，桌面 Chrome / Edge Manifest V3 扩展。可在 Windows、macOS 上按相同方式加载源码；尚未在 Mac 上实测，不支持 Safari 或手机小红书 App。

## 安装

1. 下载仓库 ZIP 并解压，或 `git clone https://github.com/2050246567zb-coder/people-lens.git`。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中仓库内的 **`extension/`** 文件夹。
4. 打开插件设置，填写自己的 API 地址、API Key 和模型名，保存并授权模型域名。
5. 刷新已登录的小红书网页，打开笔记，点击评论或楼中楼的“回复”。

直接加载不需要 Node.js、npm、构建或安装依赖。更新后重新加载扩展并刷新小红书；卸载会清除扩展本地配置。

## 已有功能

- 自定义 OpenAI 兼容的 `chat/completions` API，仓库不含 Key。
- 最近 X 条、最早 X 条、混合 X 条三选一，X 为总条数；混合可调整最早、中间、最近的权重。
- 本地读取主页和笔记，缺失正文默认用最多 3 个后台标签页并行补齐，可调 1–5 路。
- 默认 10 条、文字分析、约 180 字介绍；自定义关注点、长度和可选图文分析。
- 介绍中的小众词高亮，悬停查看随介绍一起生成的释义。
- 人物介绍完成后自动预生成 3 条回复建议，**点击“回复建议”才展开**。支持复制和手动换一组，不自动填写或发送。
- 卡片对齐回复区域，跟随网页背景色，使用较大的正文字号。

最早和混合受取数预算限制，未取完整列表时只代表已经取得的内容。无日期时不能核实最近顺序。不承诺每次拿到 10 篇完整正文或固定秒数。

## 数据与范围

取数在用户自己的浏览器里完成，不使用云端抓取。所选公开资料会发送到用户配置的模型服务；自动预生成建议还会发送当前笔记、目标发言和必要上文，因此可能增加模型费用。图文模式会发送选中的图片。

API Key 存在扩展本地存储，不注入小红书页面，不发往开发者服务器。仓库不包含 API Key、浏览器登录状态或聊天记录。收藏、点赞列表、私聊不进入分析；登录失效或访问受限时不绕过验证。

目前实现小红书网页端评论和楼中楼。抖音、B 站、私聊页仍是后续方向。
