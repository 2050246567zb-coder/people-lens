# 取数、抽样和生成算法

对应 0.1.8 源码的实现说明，不代表当前版本已实测。

## 流程与资料

回复 click → 绑定发言作者和对话 → 确认回复框挂载 → 读人物缓存或本地采集 → 抽样、并行补正文、整理时间 → 一次模型请求生成介绍和词义 → 人物完成后预生成建议 → 点击按钮才展开。

同一作者不同评论可复用人物，但建议绑定本次笔记、评论、上文。未知对象不退回笔记作者。

`core.js` 校验 24 位十六进制 ID 和对应主页；访问需要的 xsec 参数只留给本地，不给模型。只读发布内容，不混入收藏、点赞列表；正文存在作者字段时校验目标。

HTML 的 `__INITIAL_STATE__` 用括号平衡扫描提取 JSON，仅将字符串外的 undefined 转 null，不用 eval/Function。`readPublicPage` 在 MAIN world 读已加载公开数据，必要时读公开 DOM。简介上限 2000 字，标题 500、单篇正文 6000；未知总数保持 null。

## 三种抽样

`core.js:sampleNotes` 按 noteId 去重，正文优先。存在有日期条目时，时间抽样使用有日期部分；全无日期时沿取得顺序选择，不能称为核实过的最近内容。

- 最近 X 条：按真实时间升序，取最后 X 条并倒序；置顶排列不影响排序。
- 最早 X 条：时间排序前 X 条。列表完整才代表整个公开列表最早，否则只是已取得内容里最早。
- 混合 X 条：X 是总数。按最早、中间、最近权重分名额，先下取整，再按余数从大到小补足，余数相同按区域顺序。三个中心索引为 0、floor((N−1)/2)、N−1；每区取距离中心最近且未使用的条目，最终升序返回。中间是条目位置，不是日期跨度中点。

默认权重 1:1:1，12 条分 4/4/4，10 条分 4/3/3。条目不足时用实际条数。

## 本地并行补全文

`collector.js:collect` 优先当前页面、短期资料缓存和普通认证 HTML，失败再开后台页。没有云端抓取；自定义模型 API 不自动具备浏览能力。

默认取数预算 15 秒，可调 5–45 秒；列表扫描预留约 65% 预算，滚动间隔 650ms，连续 3 次无增长、超时或 1000 条时停止。最近模式取得足够候选后继续分析；最早、混合在预算内加载更早内容，不承诺全历史。

缺正文默认 3 个 worker，可调 1–5。每路先对一篇取 HTML，最多 1.2 秒；失败立刻用自己的非激活标签页，最多 4.5 秒，其他 worker 继续。每路重复使用自己的页，第一路尽可能复用主页页，已有正文跳过。时间补全后重新整理抽样结果。

worker 全部 settle 后才传播错误，finally 仅关闭任务自建页。取消发生在创建页途中，也等待创建结果纳入清理，不误关用户页面。

图文默认最多 3 张，可调 1–6，取所选笔记首张可用图，并发 2、每张上限 1.5MB，仅允许的小红书 HTTPS CDN 图片。视频不下载，不转写音频。

## 缓存和恢复

- 原始资料 Map：3 分钟、最多 20 个账号；复用不延长原始时间。
- 人物结果：默认 6 小时，可调 1–72，最多 100 条。Key 为缓存结构版本、平台、用户和规范化设置的 SHA-256，包括模型配置，不在 Key 中存明文 Key。
- 建议：30 分钟、最多 60 条。Key 含人物范围、完整规范化对话、介绍和分析时间，避免相同作者不同评论串结果。
- TaskHub 合并同 key 任务，订阅者独立退出；无人订阅则取消。断线宽限 5 秒，回放最后状态。
- 前端 15 秒 ping，后台生成期间 12 秒 heartbeat，最多两次恢复原 ticket/任务。原任务丢失明确报错，不静默重新收费。

`VERSION=3` 是缓存结构版本，与 manifest 发布版本 0.1.8 独立。

## 模型

人物和词义共一次请求，建议是人物完成后的另一次。默认 temperature 0.2、max_tokens 4096；介绍字数不等于 token 上限。只有精确官方 api.deepseek.com 在快速模式加入关闭 thinking 的参数，第三方不擅加参数。

SSE 支持 UTF-8 拆包、CRLF、注释、usage 和 DONE/结束原因，也兼容非流式 JSON。首包 25 秒、人物总 60 秒、建议 45 秒。length 或断流保留输出，失败不算完整缓存，不自动付费续写，不展示或存储推理正文。

UI 隐藏统计和引用，但后台保留 requested/sampled/full/scanned/total/complete/warnings，不因隐藏 UI 就把不足资料说成完整。
