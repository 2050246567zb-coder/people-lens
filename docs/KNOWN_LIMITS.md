# 当前边界

- 本次按用户要求没有运行测试、语法检查、预览验证、浏览器实测或真实模型调用，也没有在 Mac 上安装。实现说明不等于接收设备实测通过。
- 历史测试保留，部分 UI 断言基于较早的手动生成建议流程，需要以后获授权时维护，不能声称当前全部通过。
- 最近修正过第一次回复不出现、目标错绑作者、卡片抢焦点，以及建议预生成但点击才展开等问题；这是代码修改记录，并无本轮实测结论。
- 小红书 DOM、公开页面状态、登录和访问策略变化可能使取数或回复识别失效。不保证拿齐最近 10 篇正文；最早和混合受时间与已取得范围限制。
- 并行取数不保证恒定耗时。默认 15 秒预算不含模型生成，服务响应、截断和 worker 生命周期仍有影响。
- 仅兼容 OpenAI chat/completions 形态，没有独立云端抓取。Anthropic/Gemini 原生协议、搜索 API、音视频理解不是通用兼容能力。
- 人物完成后自动预生成建议可能多一次模型费用；开合不重复调用，手动换组/重试可另起请求。原任务丢失不静默付费重开。
- 人物介绍是有限公开内容的概括，不是人格测量；释义和建议也可能因歧义或信息不足出错。
- 私聊、抖音、B 站、手机 App、Safari 未实现，没有自动发言、关注、点赞。
